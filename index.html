APPLICATION 01

GPU Fit Finder

Quickly estimate model-weight memory and compare with broad accelerator memory tiers. Actual fit depends on runtime overhead, KV cache, batch size, precision, fragmentation and platform configuration.

APPLICATION 03

Benchmark Lab

Draft a repeatable performance test. This tool does not run a benchmark; it produces a test plan that an engineer can execute in a controlled environment.

Benchmark specification

Recommended test sequence

1
Warm-up runAllow kernels, caches and model workers to initialize.
2
Ramp concurrencyIncrease load gradually and record throughput plus p50/p95/p99 latency.
3
Observe GPU and hostCapture memory, utilization, power, CPU, network and queue depth.
4
Repeat and compareRun the same prompts, precision, context and settings for every candidate.

Record software versions, driver/runtime, model revision, prompt distribution and measurement method.
