# Publish with GitHub Pages

1. Open the repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/ (root)`, then save.
4. Wait for GitHub Pages to finish building, then open the URL shown in Settings → Pages.

This is a static demo. It has no real NVIDIA integrations, backend, authentication, or live telemetry. Do not add API keys or credentials.
